## 🎭 What is Korux Theater?

**Korux Theater** is the public-facing web application of Korux — the Governed AI Workforce OS.
It is the venue where the audience enters, buys a ticket, and either watches the show or steps onto the stage themselves.

If `korux-repertoire` is our library of skills & connectors, and `korux-overture` is our open growth playbook, then **Theater is the venue where it all comes alive in front of a live audience.**

## 🗺️ The Metaphor Map

| Theater Concept | Korux Feature | Description |
| :--- | :--- | :--- |
| **Marquee / Lobby** | Landing Page | The public entrance. Product story, pricing, and waitlist capture. |
| **Box Office** | Billing & Subscriptions | Stripe-powered plans (Free / Pro / Team) with hybrid token billing. |
| **Ticket / Will Call** | Authentication | Login, session management, and account access. |
| **The Stage** | Workflow Sharing | Where end users publish and share their governed workflows. |
| **The Audience** | Community Gallery | Browse, fork, and remix workflows shared by other users. |

## ✨ Features

- [ ] **Landing Page** — Hero, product narrative, pricing, and waitlist capture.
